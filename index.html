PERFIL

Sobre mí

L4R-77 es una identidad enfocada en ciberseguridad, creada para el aprendizaje estructurado, la documentación técnica y el crecimiento profesional en seguridad defensiva.

Este portafolio representa una única identidad profesional con múltiples facetas especializadas. Cada alias cumple un propósito específico dentro de un marco de aprendizaje coherente, diseñado para desarrollar habilidades reales y demostrables mediante práctica directa.

El objetivo es crear evidencia técnica reproducible mientras se desarrolla una base sólida en seguridad defensiva, redes y administración de sistemas. Cada proyecto, laboratorio y writeup forma parte de ese proceso.

No se afirman certificaciones, títulos ni experiencia profesional. Este portafolio documenta un proceso de aprendizaje continuo respaldado por trabajo práctico y repositorios públicos.
