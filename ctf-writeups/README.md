## Writeup Template

Each writeup should follow this structure:

```markdown
# [Machine / Challenge Name]

- **Platform:** [Hack The Box / TryHackMe / PicoCTF / Custom]
- **Difficulty:** [Easy / Medium / Hard / Insane]
- **Category:** [Web / Crypto / Forensics / Pwn / etc.]
- **Date:** [YYYY-MM-DD]
- **Status:** [Completed / In Progress / Retired]

## Summary
Brief description of the challenge or machine.

## Methodology
Step-by-step approach without directly revealing flags.

## Tools Used
- Tool 1
- Tool 2

## Lessons Learned
Key takeaways from this challenge.

## References
- [Link to relevant documentation]

Platform Rules Compliance

Before publishing any writeup, verify the platform's rules:

    Hack The Box: Writeups allowed for retired machines only.
    Active machines require approval.

    TryHackMe: Writeups generally allowed. Check specific
    room rules.

    PicoCTF: Writeups allowed after competition ends.

    Custom Labs: Only publish authorized environments.

Always respect platform rules. When in doubt, do not publish.
What Belongs Here

✅ Authorized CTF writeups following platform rules.

✅ Custom lab documentation with authorization.

✅ Methodology explanations and lessons learned.

✅ Templates for consistent documentation.
What Does NOT Belong Here

❌ Writeups for active machines where prohibited.

❌ Direct flag reveals without educational context.

❌ Real credentials, tokens or API keys.

❌ Solutions to ongoing competitions.

❌ Platform-proprietary content.
Security Notice

This repository documents authorized security practice only.

    No credentials, secrets or tokens.

    No real target information.

    All content is for educational purposes.

    Platform rules are respected at all times.
